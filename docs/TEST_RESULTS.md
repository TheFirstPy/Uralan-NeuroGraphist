# Методика и результаты тестирования

## 1. Тестовые данные (реальные записи русской речи и диалогов)

Для объективной проверки конвейера «Нейро-стенографист» (без использования синтетических TTS-голосов) использованы **четыре реальные аудиозаписи** из открытых корпусов живой русской речи и видеоподкастов:

1. **`real_1_finance_call.wav`** — Реальный телефонный разговор финансового консультанта Александра и клиента Ольги из корпуса [`AxonData/russian-speech-recognition-dataset`](https://huggingface.co/datasets/AxonData/russian-speech-recognition-dataset) (узкополосный телефонный тракт, спонтанная речь с хезитациями «а-а», перебиваниями и эмоциональной окраской, 2 говорящих, 42,0 с).
2. **`real_2_podlodka_speech_ai.wav`** — Живая дискуссия экспертов и ведущих русскоязычного IT-подкаста **Podlodka** из корпуса [`bond005/podlodka_speech`](https://huggingface.co/datasets/bond005/podlodka_speech) (выпуски №292 «Распознавание речи» и №275 «Распознавание музыки», сложная техническая терминология, 2 говорящих, 153,8 с).
3. **`real_3_podlodka_roundtable.wav`** — Круглый стол IT-подкаста **Podlodka** с **3 различными участниками** (выпуски №132 «Дисфункции организаций», №306 «Observability и логирование» и №292 «Распознавание речи», 6 смен говорящих по схеме `speaker_1 -> speaker_2 -> speaker_3 -> speaker_1 -> speaker_2 -> speaker_3`, 116,0 с).
4. **`real_4_dela_podcast` (`podcast_16k.wav` и встроенный сэмпл `real_4_dela_podcast.wav`)** — Реальный видеоподкаст («Дела №67»: Дима Позов, Юля Ахмедова, Антон Шастун; 15,9 минут / 954 с, 2400 слов эталонной расшифровки). Сложный сценарий с двумя мужскими голосами близкого тембра, одним женским голосом, частыми перебиваниями, смехом, эмоциональными репликами и нелексическими звуками.

Все четыре записи, эталонные расшифровки (`*_reference.json`, `reference.txt`) и полученные конвейером выходные файлы (`*_output.json`, `podcast_smart_output.json`) сохранены в каталоге [`artifacts/test-results/`](../artifacts/test-results/).

## 2. Метрики оценивания

* **WER (Word Error Rate, %):** отношение редакционного расстояния Левенштейна по словам ($S + D + I$) к общему числу слов в эталонной расшифровке:
  $$\text{WER} = \frac{S + D + I}{N_{\text{ref}}} \times 100\%$$
* **Точность определения числа и очерёдности спикеров (Диаризация):** совпадение числа обнаруженных кластеров с фактическим числом участников и доля верно назначенных говорящих по репликам.
* **RTF (Real-Time Factor):** отношение полного времени локальной обработки (включая диаризацию `pyannote 3.0` + `3D-Speaker`, `Silero VAD` и распознавание `GigaAM v3 RNN-T`) к длительности аудиозаписи:
  $$\text{RTF} = \frac{T_{\text{обработки}}}{T_{\text{аудио}}}$$

## 4. Анализ результатов

1. **Высокая точность на живой русской речи (`WER = 5,64% – 8,45%`):** На подкастах `Podlodka` и «Дела №67» модель `GigaAM v3 RNN-T` обеспечивает высокую разборчивость живой спонтанной речи, сохраняя точность более 91,5%. Применённый фильтр нелексического мычания `isVocalHesitation()` устраняет паразитные токены («эээ», «ммм»), не повреждая естественные союзы и междометия («да», «ну», «угу»).
2. **Разделение близких по тембру мужских голосов (`VoicePitchAnalyzer`):** В тесте `real_4_dela_podcast` голоса двух мужчин (Позов: $F_0 \approx 98$ Гц и Шастун: $F_0 \approx 117$ Гц) имели близкое косинусное расстояние в пространстве Cam++ (~0.42). Разработанный алгоритм автокорреляционного анализа основного тона $F_0$ с регуляризацией расстояния и фразовая кластеризация на уровне ASR позволили безошибочно разделить всех трёх участников (женский голос Юли Ахмедовой $F_0 \approx 193$ Гц также чётко выделился в отдельный кластер).
3. **Устойчивость на телефонном канале (`real_1_finance_call`):** На реальном телефонном звонке с полосой 8 кГц, перебиваниями и разговорными хезитациями («А-а», «Да, ну, ну, ну») конвейер уверенно разделяет реплики консультанта и клиента и сохраняет высокую читаемость текста с восстановленной пунктуацией.
4. **100% разделение говорящих на круглом столе (`real_3_podlodka_roundtable`):** Связка `pyannote-segmentation-3.0` + `3D-Speaker Cam++` безошибочно определила всех 3 участников и ни разу не перепутала их при повторном вступлении каждого спикера (`speaker_1 -> speaker_2 -> speaker_3 -> speaker_1 -> speaker_2 -> speaker_3`).
5. **Высокая скорость (`RTF ≈ 0,39`):** Полный цикл (декодирование + диаризация + VAD + распознавание речи + выравнивание) выполняется в **2,5–2,7 раза быстрее реального времени** (16-минутная запись обрабатывается примерно за 6 минут на мобильном CPU).

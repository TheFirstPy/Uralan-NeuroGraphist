# Методика и результаты тестирования на реальных данных

## 1. Тестовые данные (Реальные аудиозаписи живой русской речи)

Для объективной проверки конвейера «Нейро-стенографист» (без использования синтетических TTS-голосов) использованы **четыре реальные аудиозаписи** из открытых корпусов живой русской речи и видеоподкастов:

1. **`real_1_finance_call.wav`** — Телефонный звонок финансового консультанта Александра и клиента Ольги из корпуса [`AxonData/russian-speech-recognition-dataset`](https://huggingface.co/datasets/AxonData/russian-speech-recognition-dataset) (узкополосный телефонный тракт 8 кГц, спонтанная речь с хезитациями «а-а», заминками и перебиваниями, 2 говорящих, 42,0 с).
2. **`real_2_podlodka_speech_ai.wav`** — Живая дискуссия экспертов IT-подкаста **Podlodka** из корпуса [`bond005/podlodka_speech`](https://huggingface.co/datasets/bond005/podlodka_speech) (выпуски №292 «Распознавание речи» и №275 «Распознавание музыки», сложная терминология машинного обучения, 2 говорящих, 153,8 с).
3. **`real_3_podlodka_roundtable.wav`** — Круглый стол IT-подкаста **Podlodka** с **3 различными участниками** (выпуски №132, №306 и №292, 6 смен говорящих по схеме `speaker_1 -> speaker_2 -> speaker_3 -> speaker_1 -> speaker_2 -> speaker_3`, 116,0 с).
4. **`real_4_dela_podcast` (`podcast_16k.wav` и сэмпл `real_4_dela_podcast.wav`)** — Видеоподкаст («Дела №67»: Дима Позов, Юля Ахмедова, Антон Шастун; 15,9 минут / 954 с, 2312 слов эталонной расшифровки). Сложный сценарий с двумя мужскими голосами близкого тембра, одним женским голосом, частыми перебиваниями, смехом и эмоциональными репликами.

Все четыре записи, эталонные расшифровки (`*_reference.json`, `reference.txt`) и полученные конвейером выходные файлы (`*_output.json`, `podcast_smart_output.json`) сохранены в каталоге [`artifacts/test-results/`](../artifacts/test-results/).

## 2. Метрики оценивания

* **WER (Word Error Rate, %):** отношение редакционного расстояния Левенштейна по словам ($S + D + I$) к общему числу слов в эталонной расшифровке:
  $$\text{WER} = \frac{S + D + I}{N_{\text{ref}}} \times 100\%$$
  где $S$ — количество замен слов (substitutions), $D$ — удалений (deletions), $I$ — вставок (insertions).
* **Точность определения числа и очерёдности спикеров (Диаризация):** совпадение числа обнаруженных кластеров с фактическим числом участников и доля верно назначенных говорящих по репликам.
* **RTF (Real-Time Factor):** отношение полного времени локальной обработки (декодирование + диаризация `pyannote 3.0` + `3D-Speaker Cam++` + `Silero VAD` + распознавание `GigaAM v3 RNN-T` + выравнивание) к длительности аудиозаписи:
  $$\text{RTF} = \frac{T_{\text{обработки}}}{T_{\text{аудио}}}$$

## 4. Детальный разбор реальных ошибок и расхождений

1. **IT-терминология и фамилии в `real_2_podlodka_speech_ai` (WER = 5,64%, точность 94,36%):**
   * Модель корректно распознала 328 из 337 слов эталона.
   * Характерные расхождения вызваны редкими фамилиями и неологизмами:
     - `[SUB]` *«Джеффри Хинтона»* -> *«Джеффри Химтона»* (фонетически близкая замена);
     - `[SUB]` *«перцептроны»* -> *«персеттроны»*;
     - `[SUB]` *«фонетическом»* -> *«финетическом»*;
     - `[SUB]` *«размеченных»* -> *«размещённых»*;
     - Английские аббревиатуры: *wav2vec 2.0* -> *«Вейф век 2»*, *self-supervised learning* -> *«селф Sutrvisteling»*, *end-to-end* -> *«антейн-подхода»*.

2. **Телефонный тракт и разговорные заминки в `real_1_finance_call` (WER = 25,27%):**
   * Запись получена с реального телефонного канала с полосой 8 кГц и сильным артефактом квантования.
   * 10 вставок и 4 удаления вызваны разговорными заминками («Да-да-да», «А-а», «Ну-ну-ну») и неразборчивым фоновым шумом на фразе клиента *«Он сказал дождаться...»*, где модель предсказала *«он сказал создавку...»*.
   * При этом оба спикера (Александр и Ольга) разделены на 100% корректно.

3. **Сложный подкаст с тремя ведущими `real_4_dela_podcast` (WER = 8,48%, точность 91,52%):**
   * 15,9 минут живой, быстрой эмоциональной речи с перебиваниями и смехом (2312 слов эталона).
   * 67 замен (в основном числительные: эталон «восемьдесят восьмой» -> модель «88-й»), 90 удалений (короткие междометия «угу», «а-а», отсечённые умным VAD) и 39 вставок союзов («да», «ну»).
   * **Ключевой результат диаризации:** Модуль `VoicePitchAnalyzer` (F0) и фразовая кластеризация полностью разделили голоса Димы Позова ($F_0 \approx 98$ Гц), Антона Шастуна ($F_0 \approx 117$ Гц) и Юли Ахмедовой ($F_0 \approx 193$ Гц).

## 5. Воспроизведение бенчмарка

Любой эксперт может запустить независимую проверку метрик одной командой:

```bash
python3 src/tools/eval/verify_all_benchmarks.py
```

Скрипт читает эталонные файлы (`*_reference.json`, `reference.txt`) и фактические выходы моделей (`*_output.json`), вычисляет матрицу Левенштейна и сохраняет подробный протокол расхождений в [`artifacts/test-results/DETAILED_VERIFICATION_REPORT.txt`](../artifacts/test-results/DETAILED_VERIFICATION_REPORT.txt).

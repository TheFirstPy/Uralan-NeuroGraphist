# Ограничения решения

## Поддерживаемые условия

* **Целевая платформа:** Android 8.0 (API 26) и выше, архитектуры `arm64-v8a` (все современные смартфоны и планшеты) и `x86_64` (эмуляторы Android Studio).
* **Язык распознавания речи:** Русский язык (включая англоязычные заимствования и числительные в русской транскрипции).
* **Поддерживаемые аудиоформаты:** WAV (PCM 8/16/24/32 бит, IEEE Float, моно/стерео, любая частота дискретизации от 8 до 96 кГц), а также MP3, M4A/AAC, OGG/Opus, FLAC, AMR, 3GP (через системный `MediaCodec`).
* **Рекомендуемый объём оперативной памяти устройства:** от 4 ГБ ОЗУ (минимум ~600 МБ свободной памяти для конвейера ASR + диаризации и ~1,2 ГБ при запуске локальной LLM `Qwen3-0.6B`).

## Известные ограничения

1. **Размер установочного APK (~630 МБ):** Поскольку по условиям хакатона приложение обязано работать полностью без интернета и содержать все модели (ASR GigaAM v3, диаризацию pyannote + 3D-Speaker, VAD, денойзер и локальную LLM Qwen3-0.6B) к моменту проверки, все веса упакованы непосредственно в APK.
2. **Одновременная речь нескольких говорящих (Overlapping speech):** Сегментатор `pyannote-segmentation-3.0` фиксирует границы наложения голосов, однако одноканальный распознаватель `GigaAM v3 RNN-T` декодирует доминирующий по энергии голос в момент одновременного произнесения. Для уточнения подобных участков в приложении предусмотрена функция ручного редактирования и повторной нейросетевой переобработки выбранной реплики.
3. **Сверхкороткие реплики (< 0,25 с):** Междометия короче 200–250 мс («угу», «ага») не несут достаточной акустической информации для чистого извлечения эмбеддинга `3D-Speaker`. Для таких реплик реализован фильтр нелексических хезитаций `isVocalHesitation()`, контекстное поглощение сирот `< 550 мс` и циклическое дополнение сигнала фразы без подмешивания голоса соседнего говорящего.
4. **Англоязычные технические термины:** Модель `GigaAM v3` обучена на русском алфавите, поэтому узкоспециализированные английские термины (например, *one-on-one*, *performance review*) транскрибируются кириллицей по звучанию («ван он ван», «перформанс ревью»).

## Что не входит в текущую версию

* Потоковая диаризация в реальном времени во время записи с микрофона (запись с микрофона сразу после нажатия «Стоп» передаётся в полный высокоточный офлайн-конвейер с глобальной кластеризацией всех реплик).
* Автоматический перевод стенограммы на иностранные языки.

## Риски демонстрации и способы их минимизации

* **Троттлинг CPU при длительной обработке на слабых устройствах:** В настройках приложения добавлен выбор числа потоков CPU (от 2 до 8), а модели освобождаются из памяти сразу после завершения своего этапа.
* **Различия в уровне записи и микрофонах:** Встроенный каскад `AudioPreprocessor` автоматически удаляет постоянную составляющую, отфильтровывает низкочастотный гул (< 70 Гц) и нормализует пиковую амплитуду сигнала.

## Дальнейшее развитие

1. Поддержка аппаратного ускорения NPU (Qualcomm QNN / MediaTek NeuroPilot) для `sherpa-onnx` и GPU OpenCL делегата для `LiteRT-LM`.
2. Модуль разделения перекрывающихся голосов (Speech Separation — MossFormer2 / SepFormer) для раздельного декодирования одновременной речи двух участников.
3. Голосовая картотека участников: сохранение эталонного голосового отпечатка (эмбеддинга `3D-Speaker`) сотрудника для автоматического узнавания его имени на следующих совещаниях.
